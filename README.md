# NodeLink

A node-based pattern generator in one HTML file. Place up to nine nodes, pick a mode, and NodeLink grows a design between them: circuit boards, synaptic webs, spiderwebs, lightning, nebulae, constellations, foam, microscope slides, arcane circles, geometrical schematics, stained glass, cathedral glass and vines.

**Live:** https://fjallderall.github.io/nodelink/

## What it does

- **Modes and layers**: one mode per design, plus an optional second layer in another mode.
- **Composition**: symmetry (rotational and kaleidoscope), boundaries (circle, square, pentagon, hexagon), page formats, design scale, rotation and position.
- **Animation**: Draw on, Drift, Morph, Flow and per-mode effects (current, twinkle, strikes, wind, bloom, seasons, falling petals, sunlight, breathing, microscope life, turning rings).
- **Exports**:
  - PNG with transparency, at a chosen size and DPI (for Procreate and print)
  - strokes SVG (editable vector)
  - cut SVG for Cricut / Silhouette vinyl, iron-on, paint stencils and laser cutting, with minimum line width, gap and piece size per material
- **Library**: save and load designs as `.json`, favourites, undo / redo.

Everything runs in the browser; nothing is uploaded.

## Running it

Open `index.html` in a browser, or use the live site. No build step, no dependencies.
